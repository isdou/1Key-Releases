# 1Key 1.0.0

首个面向普通用户的公开版本。

## 功能

- 集中查看 AI 编程订阅额度、周期和重置时间。
- 查看 API 账户余额、连接状态、响应时间和可用模型。
- 支持 macOS 顶部菜单栏多账号展示，并可分别配置下拉列表与常驻项目。
- 支持本机 Token 和成本估算。
- 首次扫描后不再自动扫描；刷新只处理已添加账号。
- API Key 和凭证通过 macOS 钥匙串保存在本机。

## 安装

下载 `1Key-1.0.0.dmg`，打开后将 1Key 拖入“应用程序”。安装包同时支持 Apple Silicon 与 Intel Mac，需要 macOS 14 或更高版本。

本版本已使用 Apple Developer ID 签名并通过 Apple 公证。
